# 2026-11-18 决斗/观战/回放页更新说明

截止时间：2026-11-18 03:00

## 本次重点

### 1. 状态模型（P0）

- `UpdateData` 场上区域改为字段级合并，不再整区删除重建。
- 表侧公开卡在快照中变空位才删除；里侧未知卡保留。
- `UpdateCard` 原地更新，不替换卡对象。
- `Set` 复用 Move 已创建的卡，保留素材/known/对象身份。
- 超量宿主离场时清素材，不再把 `mats` 带进墓地。
- `ReloadField` 恢复场地占位、表示形式、XYZ 数量、连锁、手牌/墓地/除外张数。

### 2. 额外怪兽区（EMZ）

- `emz:L / emz:R` 的渲染、对账、盖卡兜底、翻面/位置动画、指示物刷新、素材角标、素材菜单全部走统一映射。
- R#9706 等回放的 `assertParity()` 已覆盖 EMZ。

### 3. 视觉

- 对象 `◎` + 源→对象连线（带箭头）。
- 连锁 C1→C2 顺序线。
- 装备 `⚙` 标记。
- 场地封锁白色 X。
- 卡组顶明牌、ReverseDeck、SwapGraveDeck 占位。
- 盖卡/手牌洗牌抖动、ShuffleSetCard 抖动。
- 胜利横幅。
- 回放双击/手机长按卡图放大。
- 动画移动改为按目标节点 key 隐藏（`u<uid>` / `z:` / `h:`），不再按卡号批量隐藏；Start/跳转时清空旧 v2 节点。
- 回放快捷键：Space、←/→、±、Home/End、R、F、Esc。

### 4. 聊天

- 决斗/观战日志栏底部聊天输入条，`position: sticky` 固定在底部。
- `/` 聚焦，Esc 失焦，Enter 发送。
- 消息前缀显示玩家名 / `[系统]` / `[观战]`。

### 5. 观战状态

- 观战徽标显示 `· N 人观战`。
- `MatchKill` 显示 `⚠ 比赛中止`，`Retry` 显示 `↻ 重试对局`。

## 已知差距

1. 动画仍复用 `.rp-fly` 替身；已有 1.8s 隐藏上限 + 3.5s 替身超时清理。
2. TagSwap 的 MZONE/SZONE 依赖后续 UpdateData。
3. ReloadField 的具体手牌/墓地卡等待 UpdateData。
4. PlayerHint 的 PHINT_DESC 计数未展示。
5. 本地 `.yrp` 文件回放未支持（`.yrp` 是响应流，不是可直接渲染的消息流）。
6. 回放页无聊天连接。
7. FieldDisabled 极端手动换边仍需实战验证。
8. DIY/先行卡缺文本表时不显示说明。
