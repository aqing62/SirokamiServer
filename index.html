玩法规则

服务器默认使用 Genesys-Ext 专属禁卡表，可通过房间密码切换规则：

（不输入）Genesys-Ext 模式
LF2OT 合表模式
NF无禁限模式
M三局两胜（BO3）
T双打模式
C编年史模式（随机卡组对战）
LP数字设置基本分（如 LP8000）
TM数字设置回合时限（秒）
ST数字设置开局手卡数
DR数字设置回合抽卡数
NS不洗切卡组

多个代码可组合使用，如 T,C#32 = 双打编年史房间，代码后加 # 再接房间名

怎么玩：进 M# 房或随机天梯房，双方登录官网账号即自动开赛

计分：胜 +10（对手分高最多再 +5）、平 +5、负 +0、每日首胜 +2；需双方已登录、非同一账号 / 同 IP 才计分

投降：当天第 N 次投降扣 N 分（最多 -10），次日重置

上榜：打完 5 场定级赛即可进榜；段位按活跃玩家百分比（巅峰 / 大师 8% / 钻石 18% / 黄金 35% / 白银 60%）；每赛季积分 ≥150 可投稿 DIY

房间内指令：

/register 用户名 密码 显示名注册新账号（首次）
/login 用户名 密码登录已有账号
/rating查看自己积分
/rating 玩家名查看指定玩家积分
/ladder查看天梯排行榜
/winnerdeck 玩家名查看该玩家天梯胜者卡组

房间代码 C，服务器为双方随机分配卡组，展开公平的即兴对决

🎴 双方各获得不同的随机卡组，就位后直接开始对战

📊 每张卡片设有分值，卡组总分 ≤ 100 分，确保对局相对平衡

📚 卡组池由策划组精心挑选，持续更新中，欢迎投稿
