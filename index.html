一、点数制定原则

本服务器所有 DIY 卡片的点数，以卡效评估为核心标准，评估主要参考两大维度：效果的适用范围 / 发动难度、效果带来的收益。

  1. 分值保底规则：DIY 卡片基础点数最低为 1 分；官方卡异画版本不遵循此保底，可保留 0 分。主卡组、额外卡组计分逻辑相互独立，同时会根据卡种差异做区分。
  2. 叠加罚分规则：同一张卡片具备多项高收益效果时，评分会追加罚分，控制单卡强度上限。
  3. 卡片点数低于标准模型：目的是保留卡组系统本身的特色。前提是官方与 DIY 创作者均不会恶意利用这类低于模型分值的卡片。
  4. 卡片点数高于标准模型：常见诱因包括玩家多次反馈投诉、效果边界模糊难以评估、卡片设计存在不合理之处，或是 DIY 作者主动提出调整建议。
  5. 点数偏差补充说明：部分卡片会存在评估滞后、尚未二次复核的情况，由此出现点数不合适的问题，可走点数缓和上诉流程提交申请。
二、点数缓和调整流程
重要前置：卡组分数过高、过低均支持点数上诉申请，二者区别在于【是否需要提前完成自查步骤】。
  1. 判断卡组分数状态
    • 情况 A：卡组分数过高 → 需要依次完成第 2、3、4 步自查调整，才可上诉
    • 情况 B：卡组分数过低 → 无需执行 2、3、4 步自查，直接跳转至第 5 步提交上诉
  2. 替换高分泛用卡：尝试将卡组内高分泛用卡更换为低分泛用替代品。
  3. 梳理系统卡池：调整卡组系统组件，审视本系统内全部 DIY 卡片。
  4. 测试平衡玩法：摸索、测试该系统更加健康合理的构筑与玩法。
  5. 提交上诉申请：携带卡组信息，提供自身服务器 ID，对目标卡提交上诉 / 参考卡上诉。
  6. 等待上诉结果（三选一）
    • 结果 A：上诉成功，目标卡片点数下调
    • 结果 B：上诉成功，参考卡片点数上调
    • 结果 C：上诉失败，卡片维持原有点数
三、补充提示
  1. 上诉提交请务必附带服务器 ID，无 ID 的申请不予受理。
  2. 上诉仅针对卡片点数合理性，不处理卡组对战胜负、单纯主观觉得强 / 弱这类诉求。
  3. 点数属于服务器动态平衡机制，单次上诉失败不代表永久无法申请；如果后续卡片环境、主流玩法发生明显变动，可以再次按照流程提交。

玩法规则

服务器默认使用 Genesys-Ext 专属禁卡表，可通过房间密码切换规则：

（不输入）Genesys-Ext 模式
LF2OT 合表模式
NF无禁限模式
M三局两胜（BO3）
T双打模式
C编年史模式（随机卡组对战）
进房即分配随机卡组并告知卡组名
LP数字设置基本分（如 LP8000）
TM数字设置回合时限（秒）
ST数字设置开局手卡数
DR数字设置回合抽卡数
NS不洗切卡组

多个代码可组合使用，如 T,C#32 = 双打编年史房间，代码后加 # 再接房间名

怎么玩：只算随机匹配（M 房）—— 双方登录官网账号即自动开赛；约房（M#）不计天梯分

计分：胜 +10（对手分高最多再 +5）、平 +5、负 +0、每日首胜 +2；需双方已登录、非同一账号 / 同 IP 才计分

投降：当天第 N 次投降扣 N 分（最多 -10），次日重置

上榜：打完 5 场定级赛即可进榜；段位按活跃玩家百分比（巅峰 / 大师 8% / 钻石 18% / 黄金 35% / 白银 60%）；每赛季积分 ≥150 可投稿 DIY
